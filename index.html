Видимость контейнеров из IFC-модели

Каждая ячейка соответствует одному контейнеру, загруженному из IFC-файла (сквозная нумерация 1–210, три таблицы — три яруса по высоте одного и того же плана 7×10). Клик скрывает/показывает контейнер на сцене. Сейчас ячейки сопоставлены с контейнерами по порядку их появления в файле — на следующих итерациях это сопоставление будет задаваться из JSON. Серые ячейки — контейнеров с таким номером в модели нет.
